# Job Hunter brand assets

Place approved final brand files here without changing application code:

- `job-hunter-mark.svg` or `job-hunter-mark.png` for the sidebar and header mark.
- `job-hunter-logo.svg` or `job-hunter-logo.png` for a full horizontal logo.
- Add the approved square app icon as `frontend/app/icon.png` so Next.js publishes favicon and app metadata automatically.

Keep SVG files vector-based. For PNG files, retain the original aspect ratio and provide at least a 512 × 512 source for the app icon. Until approved assets exist, `BrandMark.tsx` uses a graduation-cap fallback that represents the campus-career product context.
